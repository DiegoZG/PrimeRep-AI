## Tooling retries

The first Light invocation failed an immediate Optimized visibility assertion after public return from Custom because the retained scroll position was at Custom; scrolling upward before the checked-state assertion resolved it, and the complete Light run passed. The first Dark invocation searched upward for a previously selected lower card after returning to Optimized; correcting the owned flow's scroll direction resolved it, and the complete Dark run passed. A supplemental flow failed YAML parsing before device actions because a direction enum could not use environment interpolation; a static downward direction was used in the successful bounded target proof. These failed invocations are not configuration passes, and no production defect or source change is attributed to them.

## Reproduce

Use only the approved fictional fixture for `light`, `dark`, `layout`, and `restore`; the original compact guest is only for `empty`. Connect the existing development client to the coordinator's verified isolated candidate server first:

```sh
xcrun simctl openurl A21DA251-8A4F-45E3-8E6D-763EDD2277D3 'primerepai://expo-development-client/?url=http%3A%2F%2F127.0.0.1%3A8083'
maestro --udid A21DA251-8A4F-45E3-8E6D-763EDD2277D3 test -e MODE=light -e SCREENSHOT_PREFIX=/absolute/existing-dir/u25-light .maestro/workout-split-refinement.yaml
maestro --udid A21DA251-8A4F-45E3-8E6D-763EDD2277D3 test -e MODE=dark -e SCREENSHOT_PREFIX=/absolute/existing-dir/u25-dark .maestro/workout-split-refinement.yaml
maestro --udid A21DA251-8A4F-45E3-8E6D-763EDD2277D3 test -e MODE=layout -e SELECT_ID=bro-split -e SCREENSHOT_PREFIX=/absolute/existing-dir/u25-dark-max .maestro/workout-split-refinement.yaml
maestro --udid 67BF52B6-AC88-4620-841C-2970B1D5AF0D test -e MODE=empty -e SCREENSHOT_PREFIX=/absolute/existing-dir/u25-compact-light .maestro/workout-split-refinement.yaml
maestro --udid A21DA251-8A4F-45E3-8E6D-763EDD2277D3 test -e MODE=restore -e SCREENSHOT_PREFIX=/absolute/existing-dir/u25-restoration .maestro/workout-split-refinement.yaml
```

`MODE` and `SCREENSHOT_PREFIX` are required CLI environment values with no YAML defaults shadowing overrides. `layout` additionally requires `SELECT_ID`; use `full-body` for Light maximum text. Set intended appearance and text size before each run; maximum is `accessibility-extra-extra-extra-large`. Cold terminate/launch without clearing state after font-size changes avoids the previously observed warm-layout metric issue. Normal runs expect the known Optimized prefill; use `restore` at normal Large text first if needed. `glyph-proof` and `target-proof` are read-only supplements; the latter additionally requires `TARGET_ID` and uses a bounded static downward drag. Native percentages alone do not establish unobscured glyphs: inspect originals and bounded overlapping captures.
